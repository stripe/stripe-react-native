# Pinned iOS/Android differences

Every `parityGaps` entry in a fixture starts with one of these ids, for example `"G3: reason"`. `scripts/check.mjs` fails when a fixture uses an id that is not in this table, when a row lists fixtures that do not use its id (or misses one that does), or when a row is used by no fixture. The fixtures pin today's behaviour; a row is removed when the platforms are brought into line and its fixtures are updated.

Kinds: **bug** (the public types or docs promise the same behaviour on both platforms), **decision** (needs a parity decision), **wording** (same failure, different error text), **by design** (documented platform difference that still shows up as different values for one key).
